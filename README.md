# Ayesha Birthday Surprise 🎂✨

A cinematic, interactive birthday mini-site made with plain HTML, CSS and JavaScript.

## Folder structure

```text
ayesha-birthday-surprise/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── background.jpg
│   ├── book-background.jpg
│   ├── final-background.jpg
│   ├── ayesha1.jpg
│   └── ayesha2.jpg
└── audio/
    └── birthday-song.mp3
```

## Add your own photos

Put your files inside `images/` and use these exact names:

- `ayesha1.jpg` = first photo in the book
- `ayesha2.jpg` = second photo
- `background.jpg` = background behind the surprise button
- `book-background.jpg` = background behind the book
- `final-background.jpg` = background on the final wish

You can also use `.png` files, but then change the filename inside `index.html`.

## Add your song

Put one MP3 file at:

```text
audio/birthday-song.mp3
```

The song starts when the user taps **“Click This For Surprise”**. This is intentional because modern browsers commonly block audio that tries to autoplay before a user interaction.

## How the flow works

1. 3 → 2 → 1 countdown.
2. Surprise screen with falling stars/balloons.
3. User taps the surprise button.
4. Music starts and the interactive book slides in from the right.
5. The cover opens.
6. Swipe/drag right-side pages to flip.
7. Three inside pages contain photos + wishes.
8. After the last page, close the book.
9. The final full-screen birthday wish appears.

## GitHub Pages

Upload all files/folders to a GitHub repository, then:

**Settings → Pages → Deploy from branch → main → / (root) → Save**

Your GitHub Pages link will then be generated by GitHub.

## Important

Keep file names exactly the same unless you update the paths in `index.html`.
